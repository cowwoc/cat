# Path Filter

Codex-specific rule stubs include path-scoped rule bodies on demand because Codex does not natively
support `paths` frontmatter and does not currently intercept pre-read hooks for direct file reads.

A parent rule declares:
- `paths`: glob patterns for files covered by the rule.
- `Lazy load`: the file containing the full rule body or topic body. Relative includes resolve from the parent rule file; absolute
  includes are generated by SessionStart and point into the CAT plugin data directory.

When a parent rule applies this convention: before reading, searching, or editing a file whose repository-relative
path or basename matches any entry in `paths`, follow the matching `Lazy load` declaration.
